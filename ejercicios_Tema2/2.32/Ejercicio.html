Propiedad CSS: display

El atributo display en CSS determina cómo se muestra un elemento en la página web. Algunos de los valores más comunes son:

block: El elemento se muestra como un bloque, ocupando todo el ancho disponible y comenzando en una nueva línea.
inline: El elemento se muestra en línea con otros elementos, ocupando solo el espacio necesario.

inline-block: Combina características de block e inline, permitiendo que el elemento tenga dimensiones pero se comporte como un elemento en línea.

none: El elemento no se muestra en absoluto, y no ocupa espacio en el diseño.
